# 操作说明

## 1. 创建和打开项目

- 在首页点击 **新建项目**，填写项目名称和描述。
- 点击项目卡片进入项目工作区。
- 项目数据会自动保存在本地，无需联网。

## 2. 配置题型和难度

- 在 **题型设置** 中维护单选题、多选题、判断题和简答题等题型。
- 每个题型可以设置可用难度和默认倒计时时长。
- 在 **难度设置** 中新增、排序或停用难度。

## 3. 导入题目

- 进入 **题目导入**。
- 可以先点击 **生成导入模板** 下载表格模板。
- 按模板填写题干、选项、答案、解析、标签等信息后导入。
- 导入预览会提示合法行数和异常行数，确认无误后点击导入。

### 导入格式要求

- 必填列：**题型**、**难度**、**题干**、**正确答案**。
- 题型和难度需要与当前项目配置中的名称一致。
- 选项可以填写在 **选项1**、**选项2**、**选项3** 等多列中，空选项列会自动忽略。
- 如果选项超过模板默认列数，可以继续新增 **选项9**、**选项10** 等列。
- 单选题和多选题至少需要 2 个选项；正确答案可以写选项内容，也可以写选项编号，例如 `1`、`2`。
- 多选题的正确答案可以用 `;`、`；`、`、` 或 `|` 分隔，例如 `项目保存;随机抽题;倒计时`。
- 多选题的正确答案也支持 JSON 数组，例如 `["项目保存","随机抽题","倒计时"]`。
- 判断题答案必须是 `正确`、`错误`、`是`、`否`、`true` 或 `false`；选项可以只填 2 个，也可以留空。
- 简答题答案不能为空，填写普通文本即可。
- 标签可以用 `;`、`；`、`、` 或 `|` 分隔。

## 4. 管理题目

- 在 **题目管理** 中按关键词、题型、难度、标签等条件筛选题目。
- 可批量选择、取消选择、启用、禁用或删除筛选结果。
- 只有已启用且已选择的题目会进入抽题池。

## 5. 开始抽题

- 确认项目名称、启用题型、启用难度和已选题目都满足要求。
- 点击右上角 **开始抽题**。
- 答题页会显示当前题目、选项和倒计时。
- 可暂停、重置倒计时、显示答案或进入下一题。

## 6. 音效和主题

- 在 **设置** 中切换黑白简约、彩色风格或高斯模糊风格。
- 可以选择本地音效文件，并调整音量和循环播放。
- 点击 **试听** 可预览当前提示音。

## 7. 备份和恢复

- 在 **设置** 中点击 **导出 JSON 备份** 保存当前项目。
- 点击 **导入 JSON 备份** 可恢复之前导出的项目数据。
- 建议在批量修改题库前先导出备份。

## 常见问题

### 为什么不能开始抽题？

请检查项目是否已满足以下条件：

- 项目名称不为空。
- 至少有 1 个启用题型。
- 至少有 1 个启用难度。
- 至少有 1 道已启用且已选择的题目。

### 导入后题目没有进入抽题池怎么办？

请到 **题目管理** 检查题目是否处于启用状态，并确认题目已被选择。

### 自定义音效刷新后还在吗？

浏览器预览模式下，本地音效文件只会在当前会话中保留。桌面应用的数据和项目配置会保存到本地。
